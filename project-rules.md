# Project Architectural Constraints

- Use Vanilla HTML5, modern CSS, and ES6+ JavaScript exclusively.
- No jQuery, Bootstrap, Tailwind, or external script CDNs.
- Prioritize semantic HTML over generic div containers.
- Use const by default and let only when reassignment is required.
- Never render unescaped user input with innerHTML.
- Use a mobile-first approach.
- Verify the website at 375px viewport.
- Use small atomic Git commits.
- Test each feature before moving to the next feature.
